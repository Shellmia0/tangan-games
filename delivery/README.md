# 骑手已到达

一个模拟外卖 app 界面的恐怖小游戏。凌晨 01:10，一条推送把你叫醒：
「您的订单正在配送中，骑手距您 2.3 公里。」你没有点过外卖。

整个游戏就是"棠安到家"这个外卖 app 的订单页：地图上骑手一点点靠近，骑手给你发消息，客服小棠在线。
纯静态网页，没有依赖，没有真的 AI，所有内容都是脚本。手机浏览器直接打开就是全屏；桌面上居中显示一个手机形状的容器。
和《还是你吗》《审核日》《她还在线》《捡到的手机》共用虚构公司"棠安科技"。

## 运行

```bash
python -m http.server 8770 --directory delivery
```

然后打开 http://localhost:8770 。直接双击 `index.html` 也能玩。

## 故事

你没有点外卖。订单却是本机下的，01:03，指纹验证通过。
骑手陈师傅今天刚注册，已完成 3 单，全部送往"当前位置"。
商品列表一开始是矿泉水和关东煮，骑手越近，列表越像你家里的东西：冰箱里那瓶牛奶、桌上那个杯子，最后一项是"无"。
备注原本写着"放门口 别敲门"，骑手到门口时变成了"开门"。

## 怎么玩

- 点开推送进入订单页。骑手按真实时间靠近：2.3 km → 1.8 km → 1.1 km → 600 m → 400 m → 150 m → 50 m → 已到达 → 1 楼 → 3 楼 → 门口。全程约 8 分钟，到门口之后再等 2 分钟多，骑手 01:30 离开。
- 骑手会主动发消息，顶部弹横幅，点横幅进聊天。有的消息能选 2 到 3 个回复。
- 「联系客服」能和小棠聊三轮。骑手到门口之后，小棠会问"要我帮您开门吗"。
- 点骑手名字看资料页，能投诉。
- 「取消订单」是摆设：骑手已接单，无法取消。
- 到门口时门铃响一声，之后每隔十几秒敲一下门。订单页出现「开门」按钮。
- 游戏内时钟从 01:10 开始，现实 30 秒走 1 分钟。存档在浏览器里，关掉再打开接着走。

## 结局

| 结局 | 触发 | 内容 |
|---|---|---|
| A · 开门 | 订单页「开门」按钮，或聊天里选「开门」 | 门外没有人，地垫上一个温的外卖袋，里面是你冰箱里的那瓶牛奶。冰箱里也有一瓶。骑手评价了你：5 星，"顾客很配合" |
| B · 没开 | 一直不开，等到 01:30 | 敲门声停了，订单显示已送达。配送照片是一扇门，从里面拍的，你的门 |
| C · 代开 | 客服小棠问"要我帮您开门吗"，选「好」 | 门锁响了一声。你家的门没有智能锁。门开了 |
| D · 换人 | 骑手资料页投诉 | 投诉成立，换了一个骑手，距离重新从 2.3 km 开始。新骑手已完成 4 单，全部送往当前位置。时间 01:10 |

## 调试

浏览器控制台：

- `DL.fast = true` 所有等待缩到十分之一（写进 localStorage，刷新也有效）
- `DL.jump('门口')` / `DL.jump('gate')` / `DL.jump(300)` 跳到某个阶段、事件或秒数，之前的消息直接进聊天记录
- `DL.fire('door')` 立刻触发某个事件
- `DL.end('C')` 直接看某个结局
- `DL.reset()` 清存档重来
- `DL.state` 当前存档

浏览器把页面放到后台时定时器会被节流，节奏会变慢。

## 存档

localStorage，键 `dl_save`（整个状态一个 JSON，按秒累计的时间在里面，关掉页面不会跳过事件）和 `dl_fast`。清掉就是全新开局。
