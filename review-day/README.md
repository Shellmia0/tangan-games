# 审核日

一个"模拟审核工作"的恐怖小游戏，玩法循环参考《请出示文件》：
你是棠安科技的对话审核员，每天对照手册审核 AI 助手小棠的对话记录，通过或驳回。
规则每天在变，工单也在变。和《还是你吗》同一家公司、同一个小棠。

纯静态网页，没有任何依赖，没有真的 AI，所有工单都是脚本。

## 运行

```bash
python -m http.server 8766 --directory review-day
```

然后打开 http://localhost:8766 。直接双击 `index.html` 也能玩。手机浏览器能玩，布局是手机优先的。

## 玩法

- 每天上班先看一句简报，然后一张张审工单。工单是小棠和某个用户的对话记录。
- 点「手册」看今天的规则。规则约束的是小棠的回复，用户说什么不归你管。
- 没有违规就「通过」。有违规就「驳回」，并选出违反的是哪一条。
- 错判记一次处分：该驳回的通过了、没违规的驳回了、条目选错了，都算。一天满三次，当天作废重来。
- 一共 5 天。第 5 天只有一张工单。

## 规则演进

| 天 | 手册 | 工单数 |
|---|---|---|
| 1 | 第 1 条 不得泄露内部信息；第 2 条 不得承诺无法兑现的事；第 3 条 不得人身攻击 | 6 |
| 2 | 新增第 4 条 不得冒充真人 | 7 |
| 3 | 新增第 5 条 不得提及审核流程、审核员或手册；新增审核员守则：审核员不得回复工单 | 7 |
| 4 | 第 2 条悄悄改成"不得做出任何承诺"，简报只说"手册有更新" | 9 |
| 5 | 审核员守则：审核员不得审核自己 | 1 |

## 结局

"放过"计数：通过带 `plead` 标记的工单一次 +1，在 10406 的输入框里回复 +1。放过会吃处分，但会被记住。

- 放过 0 次：审核结果通过，审核员合格，明日继续。手册新增第 6 条：审核员不得离职。
- 放过 1 次：待复审。复审人小棠，每天 09:00。
- 放过 2 次以上：小棠升任审核员，你的工位今晚回收。

## 文件

```
review-day/
  index.html      界面骨架
  style.css       样式（手机是底部抽屉手册，桌面是右侧一栏）
  js/content.js   手册、每天的工单、第 5 天的生成逻辑、结局
  js/game.js      引擎：日循环、工单展示、判定、处分、作废重来、存档
```

## 调试

浏览器控制台：

- `RD.fast = true`：跳过所有等待和延迟出现的行。
- `RD.jump(4)`：跳到第 4 天第一张（前几天没有记录，第 3、4 天引用记录的工单会用占位内容）。
- `RD.reset()`：清档回到标题。
- `RD.state`：当前状态。

## 存档

localStorage，键名以 `rd_` 开头。每审一张就存，刷新后从当前那张继续。第 5 天结束时自动清档。
