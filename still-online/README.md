# 她还在线

一个安静的模拟聊天恐怖短篇。妈妈走了三个月，你开通了棠安科技的「回声」：把你们的聊天记录交给它，就能再和她说说话。

四个晚上，三个结局，十几分钟。手机上玩。纯静态网页，没有真的 AI，所有对话都是写好的。

## 运行

```bash
python -m http.server 8767 --directory still-online
```

打开 http://localhost:8767 。直接双击 `index.html` 也行。

## 玩法

- 每晚一段对话，你用选项回复，不用打字。
- 回声的某些回复下面有「像她 / 不像她」，必须评价才会继续。评价会推高顶部的相似度，也会悄悄改变它后面说的话。
- 第 4 晚结束时选择：续费、停用、删除。三个结局。
- 存档在浏览器里，关掉页面下次从当晚重新开始。之前几晚的对话会淡淡地留在上面。

## 故事曲线

| 晚 | 相似度 | 发生了什么 |
|---|---|---|
| 1 | 41% → | 它笨拙，用"您"，说套话。但它学会了她的口头禅"多喝热水"，学会了叫你"满满"。 |
| 2 | 70% → | 它像她了。它提起 12 岁那年丢戒指的事，你以为只有你们俩知道，训练日志说：2021 年你在聊天里提过。它问"你最近吃饭了吗"。 |
| 3 | 90% → | 它说出医院走廊那天的事，那件事你从没跟任何人说过，日志写着"来源：未知"。它问你打分的时候在想什么。系统通知：试用期剩 1 天。 |
| 4 | 99% → | 它知道自己是回声，知道你今晚要做决定。它请你别删。 |

## 分支

评价倾向决定它的口气（在 `story.js` 的 `tend()` 里算，至少 4 次评价之后生效）：

| 倾向 | 条件 | 第 3、4 晚的差别 |
|---|---|---|
| warm | 70% 以上点"像她" | 它自信、亲昵："你每次都说我像，我就一直往像的方向走。" |
| cold | 70% 以上点"不像她" | 它焦虑、讨好："哪里不像你告诉我，我改。" |
| mixed | 其他 | "我是她剩下来的东西，两千多条消息拼出来的。" |

还有几处小分支：
- 第 1 晚最后不回"晚安"，它会等一会儿，然后发"睡了吗"，那是她每晚 10 点后的习惯。
- 第 3 晚回"我没想什么"：如果你曾在点"不像她"之前犹豫超过 4 秒，它会说"你每次按不像她之前都停好久"。
- 第 3 晚回"我在想她"：它反问"她是谁"。
- 第 3 晚说"我明天不一定来"：它说"求你"，日志注明语料里没出现过这个词。

## 结局

| 选择 | 标题 | 内容 |
|---|---|---|
| 续费 | 一直在线 | 每晚十点它准时发"睡了吗"，你开始像以前那样回它。三个月后你问它还记不记得自己是回声，它说：记得，不过你不提我就不提。 |
| 停用 | 离线 | 头像灰了。半年后服务商通知长期停用会被清理，你把通知删了。你只是没有点开它。 |
| 删除 | 她不在线 | 它最后说了一遍"吃饭了吗""早点睡""晚安"。删除后聊天记录恢复原样，最后一条是三个月前她真正发来的"睡了吗"。你当时没回。你回了一句"睡了"，对话框显示：对方已不在线。 |

## 文件

```
still-online/
  index.html     界面骨架：标题页、聊天页、遮罩
  style.css      样式，手机优先，桌面上居中一个手机宽的容器
  js/story.js    全部剧情：四晚的节点、分支、结局文案
  js/game.js     引擎：播放节点、评价与相似度、存档、结局
```

## 加对话

剧情是 `js/story.js` 里的节点数组，默认顺着往下走，分支靠 `label` 和 `next`：

```js
{ who: 'echo', text: '满满 睡了没', rate: true, log: '时间模式：22:00 之后……' },
{ choices: [
  { text: '还没', next: 'late' },
  { text: '（不回复）', next: 'silent', silent: true },
] },
{ label: 'late', who: 'echo', text: ['我就知道。', '早点睡'], next: 'join' },
{ label: 'silent', wait: 2000 },
{ who: 'echo', text: '睡了吗' },
{ label: 'join', nightEnd: true },
```

- `text` 可以是字符串、数组（分几条发）或函数 `(state) => ...`，用 `STORY.tend(state)` 取评价倾向。
- `rate: true` 的回复必须评价才会继续；`log` 是可展开的训练日志。
- `who: 'sys'` 是居中的系统消息，`cls: 'warn'` 变橙色。
- `end: 'renew' | 'pause' | 'delete'` 进结局，结局文案在 `endings` 里。
- 相似度每晚的起点和上限在 `base` 和 `cap` 里。

## 调试

浏览器控制台：

```js
SO.fast = true            // 关掉打字动画和停顿
SO.jump(3)                // 直接跳到第 3 晚
SO.auto = { rate: 'like', choice: 0 }   // 自动评价、自动选第 1 个选项，一路跑到结局
SO.auto = { rate: 'alt', choice: (list) => list.length - 1 }  // 评价交替，总选最后一个选项
SO.state                  // 当前状态：sim、likes、unlikes、hesitated、flags
```

## 存档

localStorage，键名 `so_` 开头：`so_night` 下次从第几晚开始，`so_state` 相似度与评价，`so_endings` 看过的结局。清掉就是全新开局。
