# 捡到的手机

一个模拟手机界面的恐怖小游戏。你在深夜的公交站捡到一部手机，整个游戏就是这部手机的屏幕：
锁屏、主屏、几个 app。翻一翻，弄清机主是谁、出了什么事。它的联系人开始给"你"发消息。

纯静态网页，没有依赖，所有内容都是脚本。手机浏览器直接打开就是全屏的手机；桌面上居中显示一个手机形状的容器。
和《还是你吗》共用虚构公司"棠安科技"，助手小棠在这里也出现。

## 运行

```bash
python -m http.server 8768 --directory found-phone
```

然后打开 http://localhost:8768 。直接双击 `index.html` 也能玩。

## 故事

机主林晚，24 岁。三个月前，她的朋友周可在和平路公交站出了事。今天 11 月 4 日是周可的生日，
林晚每年这天都去站台等末班车。现在是 23:47，手机在长椅上，人不在。

你捡起手机的这一个小时里，有个号码打了 7 次。妈妈在找她，同事在群里问她，周可的对话框一直显示"正在输入"。
相册里最后一张照片的拍摄时间是"刚刚"：站台上一个人背对镜头看手机，衣服和你今晚穿的一样。

## 怎么玩

- 锁屏上有 3 条通知和 2 个小组件。密码是 4 位数字，线索在小组件里：备忘录说"密码是可可的生日"，相册回忆说"3 年前的今天"，而锁屏上写着今天的日期。密码错 3 次，会多出一条通知，既是提示也是警告。
- 解锁后 6 个 app：消息、相册、备忘录、电话、设置、棠安助手。随便翻。
- 解锁之后事件按真实时间触发，联系人会给你发新消息，顶部弹横幅，点横幅跳到对话。有的消息能选 2 到 3 个回复。
- 棠安助手聊几轮之后会说"你不是她"，给你三个选择，对应三个结局。在那之前关机会被"别关"，回拨会"无人接听"。
- 游戏内时钟从 23:47 开始，现实每 60 秒走 1 分钟。00:00 末班车进站，是第四个结局。
- 总流程 10 到 15 分钟。存档在浏览器里，中途关掉再打开会接着送没送完的消息。

## 内容

| app | 内容 |
|---|---|
| 锁屏 | 时间、日期、妈妈 / 群聊 / 7 个未接来电三条通知、备忘录与相册两个小组件 |
| 消息 | 妈妈、周可（已去世，一直"正在输入"）、周五不加班（群聊）、138 0012 2071（未知号码）、房东老张 |
| 相册 | 11 张"照片"（CSS 色块 + 文字描述），事件会再加 1 到 2 张，时间都是"刚刚" |
| 备忘录 | 待办、给可可（没写完）、密码、购物清单 |
| 电话 | 10 条记录，未知号码 7 次未接，可回拨 |
| 设置 | 机主信息、电池 7%、定位"和平路公交站"、关机 |
| 棠安助手 | 小棠，三轮对话后揭底，给出三个结局 |

## 事件（解锁后计秒）

| 秒 | id | 内容 |
|---|---|---|
| 25 | mom1 | 妈妈："晚晚？你电话怎么一直占线"，可回复 2 选 1 |
| 60 | zhou1 | 周可："你站的地方，是我站过的地方。"，可回复 2 选 1 |
| 100 | group1 | 群里同事说路过站台看到一个人在看手机，4 条，可回复 2 选 1 |
| 150 | unknown1 | 未知号码："你还在站台上吧。""别回头。" |
| 200 | photo1 | 相册多一张"刚刚"，比上一张更近 |

另外：密码错 3 次出通知；回拨未知号码后"别打了。我就在附近。"；关机失败后"别关。"；末班车前 3 分钟小棠提醒。
助手在前两个事件触发之前不会揭底，会让你"先看看她的相册"。

## 结局

| 结局 | 触发 | 内容 |
|---|---|---|
| A · 放回 | 助手选"把手机放回原地" | 放回长椅，走出十几步它响了，第二天椅子上多了一束花 |
| B · 黑屏 | 助手选"关机"，或揭底后在设置里关机 | 黑屏里映出你身后的站牌下站着一个人 |
| C · 来了 | 助手选"回复那个号码"，或揭底后在未知号码对话 / 通话记录里联系它 | 对方说"我就在你后面"，闪光灯亮，相册多一张你的后脑勺 |
| D · 末班车 | 时钟走到 00:00 还没结局 | 空车进站，你上了车 |

## 调试

浏览器控制台里：

- `FP.unlock()` 跳过锁屏
- `FP.fire('zhou1')` 立刻触发某个事件，`FP.fireAll()` 按顺序全触发
- `FP.stage(1)` 直接解锁结局
- `FP.clock(1437)` 把时钟拨到 23:57（末班车前 3 分钟），`FP.clock(1440)` 直接末班车
- `FP.end('C')` 直接看某个结局
- `FP.fast = true` 所有等待缩到十分之一（写进 localStorage，刷新也有效）
- `FP.reset()` 清存档重来
- `FP.state` 当前存档

注意：浏览器把页面放到后台时定时器会被节流到每秒一次，对话会变慢。

## 存档

localStorage，键 `fp_save`（整个状态一个 JSON）和 `fp_fast`。清掉就是全新开局。
